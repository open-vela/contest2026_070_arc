## 一、硬件层（选型 · 利旧屏 · 外接工程）

### 1.1 平台与组成

| 部件 | 型号/规格 | 说明 |
|---|---|---|
| 主控 / 板 | Allwinner **R528S3-Gemini-S1**（sun8iw20p1，双核 Cortex-A7@ARMv7） | **openvela 大赛赞助开发板**；屏利旧自旧平板 |
| 内存 | 128MB DDR3 @400MHz | LVGL 大屏 + 音频恰好承载 |
| 存储 | 256M SPI NAND（Winbond W25N02KVZEIR） | 整包 NAND 镜像烧录 |
| 显示屏 | **BOE 1200×1920 MIPI DSI 4-lane** | 原配 T070S140B（1024×600），逆向更换 |
| 触摸 | Goodix **GT9271**（I2C 0x5D） | PB2/PB3 SDA/SCL、PB4 RST、PB5 INT |
| 无线 | **RTL8733BS** WiFi + BT | |
| 人体存在 | **LD2410B** 24GHz FMCW 毫米波（UART） | 在座检测，原用 LTR553 接近传感 |
| 环境 | LTR553 光感（ALS）+ SHTC3 温湿度（TWI2） | 自动亮度 |
| 音频 | I2S codec + 喇叭 | 本地 MP3/WAV + 提示音 |

### 1.2 硬件工程与外接

- **I2C 外部上拉**：GT9271 的 CTP_SDA/SCL 从 SOC 直出仅 3.3V，早期通信不稳（ret=-1）；在靠近触摸处焊 **2.2k 上拉**（另 INT 上拉有害、RST 上拉无效，最终保留原始电路）。
- **引脚冲突排查**：
  - **UART0 与 TF 卡共用 PF2/PF4**（SDC0）→ 禁用 UART0，改用 **UART1（PD21/PD22 mux4）**；
  - **PD21/22 被 `drv_gpio` 注册为 GPIO 输出覆盖 mux4** → 修正后换 UART3（PD10/11）一次全通，后因 **BSN20 电平转换电路**在传感器外设侧而迁回 UART1、LD2410B 迁 UART3；
  - **TWI1（PB4/PB5）与 GT9271 RST/INT 完全冲突** → GT9271 启用时跳过 TWI1 初始化。
- **利旧屏逆向**：无屏资料 → 从安卓 DTB 逆向面板参数（见驱动层）；旧屏装到赞助开发板上，传感器外部 BOM 自搭。
- **关键 BOM**：主板（openvela 大赛赞助）+ BOE 屏（利旧复用）+ GT9271（逆向）+ LD2410B（~¥15）+ 喇叭（~¥5）+ 上拉/电平小件。

## 二、驱动层（BSP / 驱动开发 · 修复）

### 2.1 显示：MIPI DSI 面板驱动（新增）

- **原点屏**：BOE 驱动来自备份，`lcd_panel_init()` 的 MIPI 命令序列从 **RK3399 三防平板（1200×1920）的安卓 DTB** 翻译而来（用 `dts-to-vela-mipi` Skill 提取/翻译）；需处理 R528 DSI 控制器与 RK 平台的差异。
- **`mipi_config` 二选一互斥**：`CONFIG_T070S140B_MIPI` 与 `CONFIG_BOE_1200X1920_MIPI` 必须互斥编译，否则全局符号 `g_lcd0_config` 重复定义。
- **分辨率被锁 1024×600 根因**：`disp2/Make.defs` 对 GEMINI_S1 **无条件编译** `t070s140b_mipi_config.c`，与 BOE 的 `_mipi_config.c` 同时定义 `g_lcd0_config`，LTO 随机选一个 → 改条件编译后 `xres:1200 yres:1920` 正确。
- **横屏实现**：应用层 LVGL 矩阵旋转与 DIRECT 渲染不兼容（Data Abort），改**驱动层旋转**（G2D `degree0`），触摸同步 90° 映射 → 驱动层横屏是唯一可行路径。

### 2.2 DSI 链路加固（公共仓候选）

- **现象**：开机偶发卡 LOGO。**根因**：`de_dsi.c:dsi_gen_wr()` 的 `while(inst_busy);` 无界自旋，面板 init 约 30 次调用中 `inst_st` 偶发不清零即 spin 死。
- **修复**：仿同文件 `dsi_dcs_wr`（有界 50 次/5ms + 强清 inst_st）补超时；`DE_WRN` 在 NuttX 为空宏须用 `DISP_PRINT`（ok-20260908-2）。建议上游对全部 gen 写路径统一加界。

### 2.3 GT9271 触摸驱动（I2C）

| 问题 | 根因 | 结论 |
|---|---|---|
| 首次读取必 NACK | GT9271 芯片瞬态行为 | worker 加"失败→重置→重试"，100% 恢复（7-25） |
| I2C 地址错 | 地址由 reset 时 INT 电平决定（0x5D=LOW / 0x14=HIGH），时序不对 | 严格 RST LOW 期间设 INT → RST HIGH → 等 50ms |
| 零长度写 | R528 TWI Driver Mode 不支持 `len=0`（下溢 0xFFFF） | probe 改发 1 字节 dummy |
| combined transfer 被误判失败 | `hal_twi_xfer` 成功返回 `count-1`，驱动用 `ret==0` 判成功 | 改 `ret==(count-1)` |
| 坐标解析错 | 坐标 mask、burst 读偏移、maxpoint、circbuf `SIZEOF_TOUCH_SAMPLE_S` 尺寸不一致 | 逐项对齐（7-26） |
| 点击无响应 | 抬起时 `touch_num==0` 直接 goto，未发 TOUCH_UP | 补发 `TOUCH_INVALID` 事件 |
| 画面 180° 颠倒 | 方向配置 | `LV_DISPLAY_ROTATION_180` |
| LCD 上电改写触摸 pinmux | `sunxi_lcd_pin_cfg()` 覆盖 PB2-PB5 | LCD 侧移除触摸 GPIO 定义，交由触摸驱动管理 |

### 2.4 音频驱动（codec / I2S）

- **短 WAV"多一声"尾音**：`tone_play_one` 只设 `hw_params` 漏 `sw_params(silence_size)`，短 WAV EOF 后 DMA 欠载重播上一段 → 补 `sw_params`（ok-20260911-19，App 侧）。
- **切歌无声（三轮攻坚）**：`ksnd_pcm_open` 的 `ref_count!=0`（声卡未真正释放）→ close 不彻底；`RD_EN` 只是 gate，**close 不保证 Ramp FSM 复位** → close 清 bit30/28 + `RAMP_SRST` 后上板切歌有声（ok-20260808-12）；另 `OFF` 分支 **RDEN 清零写反**、XPlayer 内部已销毁 sink 致 app 二次 free（UAF）。
- **麦克风关断 POP**（公共仓候选）：`sun8iw20-codec.c` 先关 ADC→延时→再断 MICBIAS。
- **量化/位深**：`adecoder` 硬编码 16bit 覆盖 24bit 位深 → 写前软件降转 S16_LE；MP3 44100→48000 重采样走已验证路径；`CONFIG_DISABLE_AUDIO=0` 放行音频链路。
- **电源寄存器铁律**：`POWER_ANA_CTL@0x348` 只能 `update_bits()` 局部操作、**禁止整写**（-7 屏闪根因）。

### 2.5 存储 / SD-MMC

- **SDMMC 多块读 DMA bug**：多块读（16）必崩，单块读正常 → 数据挂载加 ADTC 判断，恢复 `MMCSD_MULTIBLOCK_LIMIT=0`。
- **TF 卡挂载**：`cd_mode 2→3`（CARD_ALWAYS_PRESENT）；SMHC0 时钟门控/总线复位未使能问题另案定位。
- **启动慢**：`env.cfg` 无长度参数整读 50MB 分区 → 两处加长度 `2000000`。

### 2.6 其他驱动

- **LTR553 ALS 校正**：驱动 lux 补"积分时间 × 增益"校正因子 + `ratio≥0.85` 极暗估算；有效位为 **bit7**（曾因位错致原始值恒 0）。
- **LD2410B UART**：模块波特率须由出厂 **256000 改 115200**；补配置命令帧/状态与字节计数日志；零字节问题在硬件接线/供电。
- **WiFi/蓝牙**：WiFi 驱动对接 + 扫描状态机；蓝牙 H4 `open -110 ETIMEDOUT`（波特率/固件下载），定位到驱动层后挂起另案。

## 三、应用层（桌面 OS · AI 应用）

### 3.1 图形 UI（LVGL 9.1）

- **形态**：浅色 Dock 桌面（状态栏 + hero 时钟 + 天气/健康卡 + 宠物区 + 6 应用 Dock + 锁屏待机）；子页 iPad 风格（状态卡/分组列表/开关）。
- **UI 架构**：三阶段拆分，`deskmate_ui.c` 巨石 → `ui/` 7 页 + 共享构建器；全量汉化。
- **字体/图标**：内置 montserrat 字形 44/62 残缺且越界读 → fallback 链 **MiSans→fa-solid→fa-brands→montserrat**；自绘图标字体 `deskmate_icons`；dock 图标从混淆 APK（`resources.arsc`）提取 Flyme 4066 个 512×512 PNG。
- **踩坑**：`lv_color_t` 仅 3 字节（ARGB8888 需 4B）致 16KB 越界 Data Abort；LVGL 渐变+`LV_RADIUS_CIRCLE` 走 layer 致堆损坏；flex 会把 `set_width` 覆盖须用 `set_size`。

### 3.2 电子宠物

- **内容**：12 情绪 × 12/16 帧精灵（144 帧），状态机 + 成长/羁绊/饥饿/精力；触摸/喂食/命名/清档；断电持久化。
- **架构**：`pet_core`（引擎）/`pet_view`（视图）/`dm_pet`（门面）三层，public API 零改。
- **关键教训**：`ar` 归档同名 C 追加 `_N.o` 永不替换，链接器取旧占位帧（黑猫事件）→ 删旧成员重建；G2D 缩放 bug → 精灵预转 300×300 ARGB；用 PIL 生成精灵并扩容分区。

### 3.3 健康提醒

- **在座检测**：LD2410B 毫米波经 UART 应用层直读（替代 LTR553），距离按 0.75m 门吸附、阈值 1.5m 配置化；离开防抖 30s；无帧静默降级（不误报不计时）。
- **提醒逻辑**：喝水/久坐双圈 + 分级递进（L1~L3）+ 每时段限播；同 tick 弹窗排队防覆盖；本地 **23 个提示音**（断网可用）。
- **联动**：喝水达标→宠物庆祝、久坐→低落、在座→欢迎、夜间 22–6 休眠。

### 3.4 AI 对话

- **链路**：openvela `ai_agent`（内置 Skill 运行时）+ 自研 `dm_ai` WebSocket 客户端；上板验证 HTTPS/TLS 与 LLM。
- **实时语音**：豆包实时语音（ASR/TTS）；纯按钮 **PTT**（无唤醒词）；点按延录；双向流式 TTS 按官方协议重写为 seed-tts-2.0（X-Api-Key/事件帧）。
- **排障要点**：TTS seq flags/WANT_READ 死循环、ASR batch 提前 break、resp 缓冲截断、WS 缓冲 128KB、TTS 403、`start_silence_time` 类型、PA 关断顺序治尾音（静音→5ms→关 PA→关 DAC）。
- **AI 子页**：4 点按快问（无麦可测）+ 城市天气设置；llm_router 兜底、强制中文、位置预置。

### 3.5 音乐

- **播放器**：XPlayer（mp3/flac/ogg/aac/wav）+ 真实进度 + 歌单 UI；`flac/pls` parser 源码编译（预编译库为 RISC-V 不可用）；封装 `dm_sound`。
- **攻坚**：无声（writei 字节账目错误 / 24bit 位深覆盖）→ 44100→48000 重采样 → 切歌无声（声卡未释放 + Ramp FSM）→ 音频仲裁层（停音乐→播 TTS→恢复）。
- **增强**：曲目联动、状态记忆、快问打断、副歌软限幅。

### 3.6 语音编排（Voice Director）

- 按场景/时段/冷却选择本地提示音播报（坐下欢迎、回来问候）；时段问候并入、`back_cooldown_s=180`、剔空票、`hour<0` 兜底；三场景开场背景乐。

## 四、分层贯穿的关键工程纪律（源自 devlog）

1. **打包防呆**：`pack` 末尾自动跑 `check_res` 三段断言（res.fex 路径级+字节+新鲜度 / `nsh.fex==vela.bin` / 镜像含完整 res+nsh 块），失败即中断——根治 res 分区烧录不完整导致的 WiFi 0x27。
2. **资源必须进固件**：改 prebuilt/资源后须 `distclean` 全量重编（`rcS.nsh` prebuilt 增量不刷新曾致字体/配置不生效）。
3. **公共仓改动走 PR**：codec 麦克风 POP / DSI 超时 / BOE 面板 / ALS 校正 / LVGL 三 fix → `dev-ai-contest-2026`（去 P140/P141）。
4. **分层定位**：UI 层 → 服务层 → 驱动层分开排；驱动回调里禁碰 LVGL；先确认问题在哪层再动手。
